### 1. 알림 기능 확인을 위한 API

알림 설정/발송 기능은 크게 두 가지 API와 연결되어 있습니다.

### ① **알림 수신을 위한 토큰 등록 API (설정)**

프론트엔드 앱이 FCM 서버에서 토큰을 발급받은 후, 이 토큰을 백엔드에 알려주는 API입니다. 이 토큰이 있어야 백엔드가 FCM에게 "이 토큰(기기)으로 알림을 보내줘" 라고 요청할 수 있습니다.

- **API:** `PUT /users/fcm-token` (Users 탭 근처)
- **역할:** **알림 '설정'** 및 등록 역할을 합니다.
- **확인 방법:**
    1. 스웨거에서 이 API를 찾습니다.
    2. `Try it out`을 눌러 토큰(`token`) 필드에 아무 임의의 긴 문자열을 넣고 실행합니다.
    3. 응답이 `{"message": "토큰 저장 완료"}` 와 같이 나오면, 백엔드가 알림 토큰을 정상적으로 받아 DB에 저장했다는 뜻입니다.

### ② **알림 발송 확인 (테스트) API**

실제 알림이 발송되는지를 확인하는 가장 좋은 방법은 **영상 업로드(`POST /events`)** API를 사용하는 것입니다.

- **API:** `POST /events` 또는 `POST /reports/generate`
- **역할:** 이 API가 성공적으로 실행된 후, **함수 맨 끝부분에 FCM 발송 로직**이 실행됩니다.
- **확인 방법:**
    1. `PUT /users/fcm-token`으로 **유효한 FCM 토큰**을 미리 등록합니다. (실제 FCM이 작동하는 테스트 앱이 필요함)
    2. `POST /events` (또는 `POST /reports/generate`)를 실행합니다.
    3. 백엔드 로그(`docker-compose logs -f`)에서 **`fcm.send_push_notification` 함수가 에러 없이 호출**되었는지 확인합니다.
